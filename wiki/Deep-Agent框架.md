# Deep Agent 框架：智能体系统设计与企业落地

> **主题**：AI 智能体 / LangChain DeepAgents · **页数**：124 · **章节**：12 章 + 2 个附录

## 📖 内容简介

围绕 LangChain 开源框架 **DeepAgents** 的智能体系统设计与企业落地指南。前半部分打基础：智能体的定义与类型学、从符号主义到 LLM 智能体的历史演进、DeepAgents 的原理（BDI 认知架构、ReAct 推理、规划与任务分解、记忆系统）。中段聚焦**安全与部署**：安全威胁模型与沙盒隔离原理、沙盒隔离技术详解、单机部署、Docker 容器化、Kubernetes 编排，并完整呈现一条"架构演进之路"（单机 → 容器 → K8s → 企业级）。后段讲企业级安全落地、可观测性与治理、实战构建，以及未来展望。

## 👥 适合读者

- 想从"调 API"进阶到"设计智能体系统"的 AI 应用工程师
- 需要为企业搭建**安全可控**智能体平台的后端 / 平台工程师
- 关注智能体沙盒、权限与治理的技术管理者
