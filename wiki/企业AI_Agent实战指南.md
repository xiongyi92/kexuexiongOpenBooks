# 企业 AI Agent 集成与私有化部署实战

> **主题**：AI 智能体 / 私有化部署 · **页数**：221 · **章节**：25 章 · **技术栈**：Java + Spring + vLLM

## 📖 内容简介

一本写给**企业 Java 团队**的大模型落地全景手册。它不讲"怎么调 API"，而是回答一个更硬的问题：一家已经有庞大 Java 技术栈的公司，如何把 AI Agent **安全、可控、可运维**地接进现有系统，并把模型跑在自己的机房里。

全书按"**认知 → 架构 → 智能层 → 部署 → 安全 → 落地**"六段推进：先用 3 章讲清 Agent 是什么、企业 Java 栈集成 AI 的六大痛点；再用总体分层架构与集成模式给出方案；中段把私有化模型服务层（vLLM）、RAG 与向量库、Agent 编排引擎逐层拆开；随后用 5 章讲部署与高可用（单机 → Docker → K8s → 多可用区 → 多租户）；再用 5 章讲安全（STRIDE 威胁建模、数据分级脱敏、OAuth2/RBAC、提示注入防护、零信任）；最后 7 章回到工程现场——Java 实战代码、框架选型、可观测性、性能与成本治理、三个行业案例、落地方法论与 AI 治理委员会。

贯穿全书的一条主线是**"异步化与流式优先、防腐式集成"**：不让 AI 调用阻塞核心交易路径，不让模型供应商、提示词与协议版本的变化渗透进业务代码。

## 👥 适合读者

- 要在**存量 Java 系统**里接入大模型的后端工程师与架构师
- 负责企业**私有化模型平台**（GPU 集群、vLLM、K8s）的平台 / SRE 工程师
- 关心 AI 安全、合规与治理的技术管理者、安全工程师
- 正在评估"自研 vs 框架"、需要一份可执行落地路线的技术负责人

## 💡 阅读建议

1. **只想知道"能不能做、该怎么做"**：读第 1–4 章 + 第 24 章（p211 分阶段落地路线），半天建立决策框架。
2. **Java 后端动手接入**：第 3 章（痛点）→ 第 5 章（集成模式与防腐层）→ 第 19 章（完整实战代码），三章连读即可跑通一条链路。
3. **平台 / SRE**：第 9–13 章是重点，vLLM 的量化、多卡并行与 K8s GPU 调度直接可抄；配套第 21–22 章的可观测性与成本治理，才能回答"这套东西一个月烧多少钱"。
4. **安全合规**：第 14–18 章按"威胁建模 → 数据 → 身份 → 模型 → 网络"顺序读，是一条完整的安全左移链路。
5. 第 23 章三个案例建议放在最后读——它们是前面所有章节的合订本，先读容易看热闹。
