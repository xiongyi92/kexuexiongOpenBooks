# 移动支付架构设计

> **主题**：支付系统 / 架构设计 / 金融科技 · **页数**：404 · **章节**：约 36 个主题章节

## 📖 内容简介

以一个贯穿全书的**案例支付系统**为载体，从零构建支撑 **5 万 TPS** 的移动支付与数字银行平台。作者的核心观点是"架构能力的本质是**权衡力**，不是知识量"，因此书中大量呈现真实事故与决策过程：DDD 战略/战术设计、事件驱动与最终一致性、分库分表、缓存与消息队列、单元化架构、异地多活容灾、性能调优落地，以及安全合规与可观测性。既有领域建模的"道"，也有 Spring Cloud / Nacos / Apollo / Sharding-JDBC / Redis / MQ 选型的"术"。

## 👥 适合读者

- 支付、钱包、数字银行方向的**后端 / 架构工程师**
- 想学习大型分布式系统设计方法论（DDD + 事件驱动 + 单元化）的工程师
- 负责资金安全、对账清结算、风控合规的技术负责人
