1OBS 是什么、能做什么

先花一分钟搞清楚：OBS 到底是干嘛的？

OBS Studio（Open Broadcaster Software，开源广播软件）是一款免费、开源、无水印的视频录制与直播推流软件，支持 Windows、macOS、Linux 三大平台。它是全球主播、UP 主、网课老师最常用的工具之一，官方下载地址为 obsproject.com/download。

它和 Windows 自带录屏、剪映等有何区别？

能力OBS StudioWindows 自带（Xbox Game Bar / 截图工具）剪映 / CapCut 桌面版
完全免费、无水印✔ 是✔ 是基础版免费
实时直播推流（B站/抖音/视频号/YouTube）✔ 一键推流✘ 不支持✘ 主要为剪辑
多画面合成（屏幕+摄像头画中画）✔ 任意叠加部分支持剪辑时叠加
绿幕抠像 / 虚拟背景✔ 内置✘ 无基础抠像
虚拟摄像头（把 OBS 当摄像头用）✔ 内置✘ 无✘ 无
多音轨、专业滤镜、转场、插件生态✔ 极丰富✘ 无偏剪辑
定位实时采集与输出轻量录屏后期剪辑
💡
一句话总结：日常简单录个屏，Windows 自带工具就够；但要做直播、画中画、绿幕、多机位、专业录课，就用 OBS——它是免费的"准专业级"选择，且和剪映等剪辑软件是配合关系（OBS 录制 → 剪映剪辑）。

2下载与安装

认准官方渠道，避开带捆绑的"汉化版""绿色版"陷阱。

⚠️
安全提醒：请务必从官网下载。obsproject.com 才是唯一官网；网上搜到的"OBS 中文官网/绿色版/破解版"多为第三方，可能捆绑广告或病毒。
  1. 打开官网下载页访问 https://obsproject.com/download，页面会自动识别你的操作系统，点击对应按钮下载（Windows 选 Installer 安装版；macOS 选 Apple Silicon 或 Intel 对应的 .dmg；Linux 用发行版包管理器或 Flatpak）。
  2. Windows 安装双击 OBS-Studio-xx.x-Windows-Installer.exe，一路"下一步"即可。首次启动时建议勾选"运行自动配置向导"。
  3. macOS 安装打开 .dmg 文件，把 OBS 图标拖进"应用程序"文件夹。首次打开如提示"来自身份不明的开发者"，请在「系统设置 → 隐私与安全性」中点击"仍要打开"。
  4. Linux 安装Ubuntu 可用：sudo apt install obs-studio；或通用方式 flatpak install flathub com.obsproject.Studio。
  5. 首次启动首次打开会弹出「自动配置向导」，见第 5 章。之后如需更新，在「设置 → 通用」里可切换更新通道。
🪟

Windows

支持 Windows 10 及以上；强烈建议安装显卡驱动后再用硬件编码。

🍎

macOS

支持 Apple Silicon 与 Intel；首次需在系统设置里授予"屏幕录制"与"麦克风"权限。

🐧

Linux

支持 X11 与 Wayland；部分发行版需自行添加 PPA 或使用 Flatpak。

3认识主界面

OBS 界面看起来复杂，其实就 6 块区域，各司其职。

区域作用新手要点
① 菜单栏文件、设置、工具等入口「工具」里有自动配置向导、插件市场（32.0 起）
② 预览 / 节目窗口实时预览最终画面红框内的就是观众/录像看到的画面，可拖动调整各元素位置大小
③ 场景保存多套"画面组合"每个场景是一块独立画布，直播时点一下就切换
④ 来源往当前场景里添加画面/声音素材点 + 添加屏幕、摄像头、文字等，越靠上的层越靠前
⑤ 混音器控制各声音的音量与开关桌面音频=电脑声音，麦克风=你的说话声，可分别调节
⑥ 转场特效场景切换时的过渡动画默认"淡入淡出"，可改成"剪切"等
⑦ 控件开始直播/录制、设置等「开始直播」「开始录制」两个大按钮是核心
⑧ 直播状态栏CPU、帧率、丢帧、时长监控直播中若"丢帧"飙高，说明网络或性能不足（见第 11 章）

4核心概念：场景与来源

这是 OBS 最重要的两个概念，理解它，后面所有操作都一通百通。

🎨

场景（Scene）

一套固定画面组合。比如你可以建三个场景："游戏直播"（游戏+摄像头）、"开场待机"（图片+倒计时）、"结束画面"（文字感谢）。直播时点一下场景即可瞬间切换整组画面。

🧩

来源（Source）

放进场景里的单个素材：屏幕、游戏、摄像头、图片、文字、浏览器页面、音频等。一个来源可以同时被多个场景引用，也可以被嵌套成"场景来源"。

常用来源一览

来源类型用途说明
显示器采集录整个屏幕 / 演示桌面Windows/Linux 可用；多显示器时选对应屏幕
窗口采集只录某一个软件窗口适合只演示某个程序，避免露隐私
游戏采集捕获全屏 3D 游戏仅 Windows，性能最好，游戏黑屏时用它
视频采集设备摄像头 / 采集卡画面接单反、Switch、手机等要配采集卡
音频输入/输出采集单独采集某路声音桌面音频与麦克风通常已默认接入混音器
图像 / 媒体源放图片、Logo、本地视频媒体源可循环播放，用于"无人直播/片头"
文本（GDI+）加标题、字幕、水印常用来打直播间标题或"下播提示"
浏览器加载网页、弹幕、动画配合弹幕插件、互动组件、倒计时页
场景（来源嵌套）把一个场景作为素材高级用法，用于复用整套组合
色度键滤镜绿幕抠像加在摄像头来源上（见场景 5）

53 分钟快速上手（自动配置向导）

跟着向导走一遍，OBS 会自动帮你调好最适合这台电脑的参数。

  1. 打开自动配置向导首次启动会自动弹出；若错过了，点菜单「工具 → 自动配置向导」。
  2. 选择用途「优化用于直播，我是主播」或「仅用于录制，我不直播」——按你的主要用途二选一（以后可改）。
  3. 视频设置保持默认的"基础分辨率"（通常 1920×1080），帧率可选 30 或 60。担心电脑性能就选 30。
  4. 直播设置（如选了直播）选择你的平台（如 Bilibili、抖音、YouTube），或选"自定义"填入服务器与推流密钥（见第 8 章）。向导会测网速并给出推荐码率。
  5. 应用设置点「应用设置」完成。现在添加一个来源（如"显示器采集"），点右下角「开始录制」试录 30 秒，回放确认正常即可。
✅
最快上手口诀：① 跑自动配置向导 → ② 来源点 + 添加"显示器采集" → ③ 混音器拉大"桌面音频/麦克风"音量 → ④ 点「开始录制」。四步即可录下第一段屏幕视频。

6基础设置详解

点「文件 → 设置」进入。新手建议先用"简单模式"，理解后再切"高级模式"。

6.1 视频：决定画面清晰度

选项含义建议值
基础（画布）分辨率画布大小，来源放在这个"纸面"上1920×1080
输出（缩放）分辨率最终录像/直播的分辨率1080p（性能不足可降 1280×720）
常用帧率（FPS）每秒画面张数教程录屏 30；游戏直播 60

6.2 输出：决定画质与文件大小 / 流畅度

「输出」是 OBS 最关键的设置页。简单模式下只需填几个数字；高级模式可分别细调"直播"和"录制"。

项目直播（推流）推荐本地录制推荐
编码器优先硬件编码：NVIDIA NVENC H.264 / AMD / Intel QSV；无独显用 x264同左，硬件编码更省 CPU
码率控制CBR（恒定码率，直播必须）可用 CQP/CRF（按质量，文件更小）
视频码率1080p60 约 6000~9000 Kbps；1080p30 约 4500~6000CQP 18~22（越小越清晰、文件越大）
封装格式—（直播无文件）32.x 默认 Hybrid MP4/MOV，兼容好又抗崩溃
录像路径—自定，如 D:\OBS录像
📌
码率怎么定？码率越高越清晰，但需要更大的上传带宽（直播）或更大的文件（录制）。经验值：720p≈3000–5000、1080p30≈4500–6000、1080p60≈6000–9000 Kbps。直播码率不要超过你实际上行带宽的约 70%。

6.3 音频：桌面声音 + 麦克风

在「设置 → 音频」里可指定具体设备（哪个麦克风、哪个扬声器）。若直播没声音，90% 是这里选错了设备或混音器里静音了。

7录制视频教程（录屏 / 录课）

最常用的功能之一，学会它就能做教程、录课、存档会议。

  1. 新建场景「场景」面板点 +，命名如"录课"。
  2. 添加画面来源「来源」点 +：录整个屏幕选"显示器采集"；只录某个软件选"窗口采集"。拖动四角可缩放、移动位置。
  3. （可选）加摄像头画中画再点 + 添加"视频采集设备"，选中摄像头，缩小后拖到角落，实现"人像+屏幕"同框。
  4. 确认声音看混音器：播放点声音，"桌面音频"的绿色音量条应跳动；说话时"麦克风"应跳动。没反应就回「设置 → 音频」换设备。
  5. 开始录制点「开始录制」，此时右上角会显示录制时长；录制中可随时点「停止录制」结束。
  6. 找到文件「文件 → 显示录像」即可打开保存文件夹（默认在用户"视频"目录）。
💾
重要：建议在「设置 → 输出」里勾选"录像完成后自动重封装为 MP4"或直接用 Hybrid MP4/MOV 默认格式，避免断电/崩溃导致文件损坏打不开。

8直播推流教程（B站 / 抖音 / 视频号 / YouTube）

直播的本质：把 OBS 的画面实时"推"到平台服务器，平台再分发给观众。

关键一步：获取"推流地址 + 推流密钥"

不同平台位置不同，但逻辑一致——都在各平台的"开播设置 / 直播中心 / 推流地址"里：

平台获取位置（以各平台实际界面为准）
Bilibili创作中心 / 直播中心 →「我的直播间」→「开播设置」，复制"服务器地址"和"串流密钥"
抖音抖音直播伴侣之外，可用"推流码"方式（在网页直播后台获取 RTMP 地址与密钥）
视频号视频号助手 →「直播」→「推流」，生成推流地址与密钥
YouTubeYouTube 直播 →「直播设置」，获取"流地址"和"流密钥"
🔐
密钥=直播密码，切勿截图外泄！泄露后别人可推流到你的直播间。此外，很多平台的密钥会定期变化，重新开播前记得刷新复制。
  1. 进入推流设置「文件 → 设置 → 推流」。服务选择你的平台（内置了 B站、YouTube、Twitch 等预设）；若没有，选"自定义"。
  2. 填入服务器与密钥把平台的"服务器地址"粘贴到「服务器」，把"推流密钥"粘贴到「推流码」。点「确定」。
  3. 检查画面与声音确认预览画面正常、混音器音量条在动。
  4. 开始直播点「开始直播」，回到平台后台看是否显示"直播中"。首次建议先用小号或试播测试。
  5. 监控状态盯住右下角「丢帧」：一直 0 最理想；若持续飙高，说明网速/码率不匹配，需降码率（见第 11 章）。

9八大使用场景实战

这是本教程的精华。每个场景给出"要什么来源 + 怎么搭 + 注意什么"，照着做即可。

1

游戏直播

适合：B站/抖音/YouTube 游戏主播
来源组合
游戏采集（或显示器采集）视频采集设备（摄像头）文本（标题/水印）
搭建要点
游戏来源优先用"游戏采集"（性能最好）。摄像头缩小放角落，加文字做标题或"感谢打赏"。可再建一个"开局等待"场景放封面图。
参数建议
1080p60、CBR 6000–9000 Kbps、优先 NVENC 硬编；上传带宽不足就降到 1080p30 / 720p60。
避坑
游戏黑屏 → 改用"游戏采集"并选对游戏进程；画面卡 → 关闭 OBS 预览或降码率；注意部分反作弊游戏需"窗口/显示器采集"。
2

录屏教学 / 软件演示

适合：教程 UP 主、程序员、产品演示
来源组合
显示器采集麦克风（讲解）（可选）鼠标高亮/点击效果插件
搭建要点
录整个屏幕用"显示器采集"；只想录某个软件用"窗口采集"防隐私泄露。确认麦克风音量正常，桌面音频（系统提示音）按需开关。
参数建议
1080p30 足够，本地录制用 CQP 18–20（画质高、文件适中）；编码器选硬件编码。
避坑
麦克风底噪 → 给麦克风加"降噪"滤镜；没声音 → 检查混音器与默认设备；文件过大 → 提高 CQP 数值（如 20→23）。
3

网课 / 会议（屏幕+人像画中画）

适合：老师上网课、远程汇报
来源组合
显示器采集（课件）视频采集设备（人像）麦克风
搭建要点
先加屏幕铺满，再加摄像头，缩小拖到角落形成画中画。开启"虚拟摄像头"后，在腾讯会议/Zoom/钉钉里选择"OBS Virtual Camera"即可把合成画面当摄像头用（见场景 4）。
避坑
会议软件里若选不到 OBS → 点 OBS 右下角「启动虚拟摄像头」；画面颠倒/黑屏 → 检查来源顺序（上层会盖住下层）。
4

虚拟摄像头（美颜 / 背景替换）

适合：视频会议、面试、社交软件
来源组合
视频采集设备（真实摄像头）图像（虚拟背景）文本（名牌）
搭建要点
底层放背景图，上层放摄像头并调好位置；可给摄像头加"色度键"做绿幕、或用第三方虚拟背景滤镜。点「启动虚拟摄像头」，会议软件里选"OBS Virtual Camera"。
避坑
其他软件占用摄像头时会冲突 → 先在 OBS 里关闭摄像头来源或独占；虚拟摄像头分辨率在「设置 → 视频」统一控制。
5

绿幕抠像（虚拟背景）

适合：直播换背景、网课出镜、特效画面
来源组合
图像/视频（背景，放底层）视频采集设备（绿幕前的人，放上层）
搭建要点
右键摄像头来源 →「滤镜」→ 添加"色度键"→ 颜色选绿色，拖动"相似度/平滑度"直到绿幕干净、人像边缘不破。
避坑
布光要均匀（绿幕不能有褶皱阴影）；别穿绿色衣服；抠不干净就调大"相似度"，边缘毛糙就调"平滑度/溢出抑制"。
6

多场景切换 / 多机位

适合：直播节目、多角度录制、带货
来源组合
场景A：全景（摄像头1）场景B：特写（摄像头2/采集卡）场景C：屏幕PPT场景D：片头/待机
搭建要点
每个场景独立搭建画面。直播中点击不同场景即可无缝切换；「转场特效」里选"淡入淡出"更柔和。多摄像头可配多块采集卡接入。
避坑
给常用场景设快捷键（见附录）切换更快；开启「工作室模式」可先在后台调好下一场景再切出，避免观众看到调整过程。
7

纯音频录制（播客 / 有声书）

适合：播客、配音、音乐 Demo
来源组合
麦克风（音频输入采集）（可选）媒体源背景音乐
搭建要点
不用加画面来源，只留麦克风即可。给麦克风加"降噪"+"压缩器"滤镜提升音质。录制后文件也是带画面的（黑屏或封面），可导入剪辑软件导出纯音频。
避坑
想在录像里保留多轨（人声/背景音分开）→ 用「设置 → 输出 → 高级 → 录像 → 音频轨道」配置多轨。
8

回放缓存（精彩瞬间）

适合：游戏高光、突发镜头回录
原理
OBS 在后台持续缓存最近 N 秒画面，你按一下快捷键，就把"刚刚那一段"存成文件，无需全程录像。
开启方法
「设置 → 输出 → 回放缓存」开启，设置时长（如 60 秒）；「设置 → 热键」给"保存回放缓存"设个快捷键（如 F8）。
用法
打游戏打出精彩操作 → 按 F8 → 最近 60 秒自动保存。特别适合"不想一直录、又怕错过高光"的场景。

10进阶技巧与常用插件

掌握这些，画面和效率能再上一个台阶。

10.1 给来源加滤镜

右键任意来源 →「滤镜」→ 点 + 添加。常用滤镜：

滤镜作用典型场景
降噪（噪声抑制）去除麦克风底噪、电流声录课、直播人声更干净
噪声门低于阈值的声音自动静音不说话时消除杂音
增益放大/降低音量麦克风声音太小
色度键绿幕/蓝幕抠像虚拟背景（场景 5）
色彩校正 / LUT调色、套滤镜风格画面偏色、风格化
模糊打码/模糊局部遮挡隐私信息

10.2 常用插件推荐

32.0 起 OBS 内置了"插件管理器"（菜单「工具」中），安装插件更方便。热门插件：

📱 obs-websocket

手机/网页远程控制 OBS 开始、停止、切场景。直播博主常用。

🎨 StreamFX

提供模糊背景、3D 变换、更高质量滤镜等进阶效果。

💬 弹幕 / 字幕插件

把直播弹幕显示到画面；Whisper 类插件可实时自动生成字幕。

🎛️ 高级转场 / 倒计时

丰富的转场动画、"即将开播"倒计时组件。

📌
找插件：首选 OBS 官网论坛 / GitHub 的知名项目，谨慎安装来路不明的插件。安装后重启 OBS 生效。

10.3 让画面更专业的几个小技巧

  • 转场：「转场特效」选"淡入淡出 300ms"或"剪切"，场景切换不突兀。
  • 锁定来源：预览区点来源 → 右上角"锁"图标，防止误拖动。
  • 工作室模式：右下角「控件」里开启，后台预览 + 前台播出分离，适合正式直播。
  • 快捷键：把"开始录制/停止录制/切场景/保存回放"都设上快捷键，操作快很多。

11常见问题排查

遇到问题先查这张表，基本能解决 80% 的情况。

现象常见原因解决办法
画面全黑来源没添加/选错显示器；显卡切换（笔记本双显卡）；部分窗口受保护重新添加来源并选对显示器；用"窗口采集"换"游戏采集"；关闭 OBS 用"集成显卡"或"高性能"启动
没有声音默认设备选错、混音器静音、来源没加音频「设置→音频」选对设备；混音器看音量条是否跳动、取消静音
直播卡顿/丢帧码率超过上行带宽、CPU/GPU 满载降低码率与分辨率；改用硬件编码；关掉预览；减少来源
录像文件打不开/损坏用了 MKV 没重封装、断电/崩溃用 Hybrid MP4/MOV 默认格式，或"完成后重封装为 MP4"
推流失败/连不上服务器地址或密钥填错/过期重新复制平台推流地址与密钥，确认没有多余空格
麦克风底噪大环境噪声、增益过高给麦克风加"降噪"+"噪声门"滤镜
录出来模糊码率过低、输出分辨率被缩小提高码率；确认输出分辨率为 1080p
摄像头被占用其他软件占用了摄像头关闭占用软件，或在 OBS 里重新添加该设备
