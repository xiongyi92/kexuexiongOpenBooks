# OBS Studio 新手入门完全教程（图文并茂）

> 📖 **适用版本**：OBS Studio 32.x（当前稳定版）　💻 **平台**：Windows / macOS / Linux　⏱ **阅读时长**：约 20 分钟
>
> OBS Studio（Open Broadcaster Software）是一款**免费、开源、无水印**的视频录制与直播推流软件。本文从零开始，带你学会录屏、直播、网课、虚拟摄像头等操作，并覆盖 8 大常见使用场景。

---

## 一、OBS 是什么、能做什么

OBS Studio 是**全球主播、UP 主、网课老师最常用**的视频采集工具之一，支持 Windows、macOS、Linux 三大平台。官方下载地址：[https://obsproject.com/download](https://obsproject.com/download)。

![图1-1 OBS功能总览](图1-1-OBS功能总览.png)

**图 1-1**　OBS 像一个"视频总控台"：把各种画面和声音采集进来，实时合成，再输出成录像或直播流。

### 它和 Windows 自带录屏、剪映有何区别？

| 能力 | OBS Studio | Windows 自带（Xbox Game Bar / 截图工具） | 剪映 / CapCut 桌面版 |
| --- | --- | --- | --- |
| 完全免费、无水印 | ✔ 是 | ✔ 是 | 基础版免费 |
| 实时直播推流（B站/抖音/视频号/YouTube） | ✔ 一键推流 | ✘ 不支持 | ✘ 主要为剪辑 |
| 多画面合成（屏幕+摄像头画中画） | ✔ 任意叠加 | 部分支持 | 剪辑时叠加 |
| 绿幕抠像 / 虚拟背景 | ✔ 内置 | ✘ 无 | 基础抠像 |
| 虚拟摄像头（把 OBS 当摄像头用） | ✔ 内置 | ✘ 无 | ✘ 无 |
| 多音轨、专业滤镜、转场、插件生态 | ✔ 极丰富 | ✘ 无 | 偏剪辑 |
| 定位 | **实时采集与输出** | 轻量录屏 | **后期剪辑** |

> 💡 **一句话总结**：日常简单录个屏，Windows 自带工具就够；但要**做直播、画中画、绿幕、多机位、专业录课**，就用 OBS。OBS 和剪映等剪辑软件是**配合关系**（OBS 录制 → 剪映剪辑）。

## 二、下载与安装

> ⚠️ **安全提醒**：请务必从官网下载，`obsproject.com` 才是唯一官网；网上搜到的"OBS 中文官网 / 绿色版 / 破解版"多为第三方，可能捆绑广告或病毒。

1. **打开官网下载页**：访问 [https://obsproject.com/download](https://obsproject.com/download)，页面会自动识别操作系统（Windows 选 Installer；macOS 选对应芯片的 .dmg；Linux 用包管理器或 Flatpak）。
2. **Windows 安装**：双击 `OBS-Studio-xx.x-Windows-Installer.exe`，一路"下一步"即可。
3. **macOS 安装**：打开 `.dmg`，把 OBS 拖进"应用程序"；首次打开若提示"来自身份不明的开发者"，在「系统设置 → 隐私与安全性」中点击"仍要打开"。
4. **Linux 安装**：Ubuntu 可用 `sudo apt install obs-studio`；或 `flatpak install flathub com.obsproject.Studio`。
5. **首次启动**：首次打开会弹出「自动配置向导」，见第五章。

- 🪟 **Windows**：支持 Windows 10 及以上；建议先装显卡驱动再用硬件编码。
- 🍎 **macOS**：支持 Apple Silicon 与 Intel；首次需在系统设置里授予"屏幕录制"与"麦克风"权限。
- 🐧 **Linux**：支持 X11 与 Wayland；部分发行版需添加 PPA 或使用 Flatpak。

## 三、认识主界面

OBS 界面看起来复杂，其实就 6 块区域，各司其职。

![图3-1 主界面布局](图3-1-主界面布局.png)

**图 3-1**　OBS 主界面六大区域示意（深色主题，实际可切换浅色）。

| 区域 | 作用 | 新手要点 |
| --- | --- | --- |
| **① 菜单栏** | 文件、设置、工具等入口 | 「工具」里有自动配置向导、插件市场（32.0 起） |
| **② 预览/节目窗口** | 实时预览最终画面 | 红框内就是观众/录像看到的画面，可拖动调整元素 |
| **③ 场景** | 保存多套"画面组合" | 每个场景是一块独立画布，点一下就切换 |
| **④ 来源** | 往当前场景添加画面/声音素材 | 点 `+` 添加，列表越靠上越靠前 |
| **⑤ 混音器** | 控制各声音音量与开关 | 桌面音频=电脑声音，麦克风=你的说话声 |
| **⑥ 转场特效** | 场景切换时的过渡动画 | 默认"淡入淡出" |
| **⑦ 控件** | 开始直播/录制、设置等 | 「开始直播」「开始录制」两个大按钮是核心 |
| **⑧ 直播状态栏** | CPU、帧率、丢帧、时长监控 | 直播中"丢帧"飙高说明网络或性能不足 |

## 四、核心概念：场景与来源

这是 OBS 最重要的两个概念，理解它，后面所有操作一通百通。

![图4-1 场景与来源](图4-1-场景与来源.png)

**图 4-1**　场景是一块画布，来源是铺在画布上的素材；来源列表**越靠上越靠前**，支持拖动排序。

- 🎨 **场景（Scene）**：一套**固定画面组合**。比如建三个场景："游戏直播"（游戏+摄像头）、"开场待机"（图片+倒计时）、"结束画面"（文字感谢），直播时点一下即可**瞬间切换**整组画面。
- 🧩 **来源（Source）**：放进场景里的**单个素材**——屏幕、游戏、摄像头、图片、文字、浏览器页面、音频等，可被多个场景复用。

### 常用来源一览

| 来源类型 | 用途 | 说明 |
| --- | --- | --- |
| **显示器采集** | 录整个屏幕/演示桌面 | Windows/Linux 可用；多屏时选对应屏幕 |
| **窗口采集** | 只录某一个软件窗口 | 避免露隐私 |
| **游戏采集** | 捕获全屏 3D 游戏 | 仅 Windows，性能最好，游戏黑屏时用它 |
| **视频采集设备** | 摄像头/采集卡画面 | 接单反、Switch、手机需配采集卡 |
| **音频输入/输出采集** | 单独采集某路声音 | 桌面音频与麦克风通常已默认接入 |
| **图像 / 媒体源** | 放图片、Logo、本地视频 | 媒体源可循环播放，用于片头/无人直播 |
| **文本（GDI+）** | 加标题、字幕、水印 | 常用来打直播间标题 |
| **浏览器** | 加载网页、弹幕、动画 | 配合弹幕插件、倒计时页 |
| **场景（来源嵌套）** | 把一个场景作为素材 | 高级用法，复用整套组合 |
| **色度键滤镜** | 绿幕抠像 | 加在摄像头来源上（见场景 5） |

## 五、3 分钟快速上手（自动配置向导）

1. **打开自动配置向导**：首次启动自动弹出；错过则点「工具 → 自动配置向导」。
2. **选择用途**：「优化用于直播」或「仅用于录制」，按主要用途二选一（以后可改）。
3. **视频设置**：保持默认"基础分辨率"（通常 1920×1080），帧率可选 30 或 60，性能担心就选 30。
4. **直播设置（如选了直播）**：选择平台（Bilibili、抖音、YouTube 等），或选"自定义"填入服务器与推流密钥（见第八章）。向导会测网速并给推荐码率。
5. **应用设置**：点「应用设置」完成，添加"显示器采集"来源，点「开始录制」试录 30 秒回放确认。

> ✅ **最快上手口诀**：① 跑自动配置向导 → ② 来源点 `+` 添加"显示器采集" → ③ 混音器拉大"桌面音频/麦克风"音量 → ④ 点「开始录制」。四步即可录下第一段屏幕视频。

## 六、基础设置详解

点「文件 → 设置」进入。新手建议先用"简单模式"，理解后再切"高级模式"。

### 6.1 视频：决定画面清晰度

| 选项 | 含义 | 建议值 |
| --- | --- | --- |
| 基础（画布）分辨率 | 画布大小，来源放在这个"纸面"上 | 1920×1080 |
| 输出（缩放）分辨率 | 最终录像/直播分辨率 | 1080p（性能不足降 1280×720） |
| 常用帧率（FPS） | 每秒画面张数 | 教程录屏 30；游戏直播 60 |

### 6.2 输出：决定画质与文件大小 / 流畅度

| 项目 | 直播（推流）推荐 | 本地录制推荐 |
| --- | --- | --- |
| 编码器 | 优先硬件编码：`NVIDIA NVENC H.264` / AMD / Intel QSV；无独显用 `x264` | 同左，硬件编码更省 CPU |
| 码率控制 | `CBR`（恒定码率，直播必须） | 可用 `CQP/CRF`（按质量，文件更小） |
| 视频码率 | 1080p60 约 6000~9000 Kbps；1080p30 约 4500~6000 | CQP 18~22（越小越清晰、文件越大） |
| 封装格式 | —（直播无文件） | 32.x 默认 Hybrid MP4/MOV |
| 录像路径 | — | 自定，如 `D:\OBS录像` |

> 📌 **码率怎么定？** 码率越高越清晰，但需要更大上传带宽（直播）或更大文件（录制）。经验值：**720p≈3000–5000、1080p30≈4500–6000、1080p60≈6000–9000 Kbps**。直播码率不要超过实际上行带宽的约 70%。

### 6.3 音频：桌面声音 + 麦克风

![图6-1 音频路由](图6-1-音频路由.png)

**图 6-1**　音频默认就有两路：桌面音频 + 麦克风，在混音器里调节，最终一起输出。

在「设置 → 音频」里可指定具体设备。若直播没声音，90% 是这里选错设备或混音器里静音了。

## 七、录制视频教程（录屏 / 录课）

![图7-1 录制流程](图7-1-录制流程.png)

**图 7-1**　录制流程：采集 → 编码 → 落盘为视频文件，不经过网络。

1. **新建场景**：「场景」面板点 `+`，命名如"录课"。
2. **添加画面来源**：「来源」点 `+`：录整个屏幕选"显示器采集"；只录某软件选"窗口采集"。拖动四角可缩放移动。
3. **（可选）加摄像头画中画**：再点 `+` 添加"视频采集设备"，选中摄像头，缩小拖到角落，实现"人像+屏幕"同框。
4. **确认声音**：看混音器，播放声音"桌面音频"绿色音量条应跳动；说话时"麦克风"应跳动。
5. **开始录制**：点「开始录制」，右上角显示录制时长；随时可点「停止录制」结束。
6. **找到文件**：「文件 → 显示录像」打开保存文件夹（默认在用户"视频"目录）。

> 💾 **重要**：建议在「设置 → 输出」用 Hybrid MP4/MOV 默认格式（或勾选"录像完成后自动重封装为 MP4"），避免断电/崩溃导致文件损坏。

## 八、直播推流教程（B站 / 抖音 / 视频号 / YouTube）

直播的本质：把 OBS 画面实时"推"到平台服务器，平台再分发给观众。

![图8-1 直播推流流程](图8-1-直播推流流程.png)

**图 8-1**　直播推流流程：你只需从平台拿到"服务器地址 + 推流密钥"，填入 OBS 即可。

### 关键一步：获取"推流地址 + 推流密钥"

| 平台 | 获取位置（以各平台实际界面为准） |
| --- | --- |
| Bilibili | 创作中心/直播中心 →「我的直播间」→「开播设置」，复制"服务器地址"和"串流密钥" |
| 抖音 | 网页直播后台获取 RTMP 地址与密钥（推流码方式） |
| 视频号 | 视频号助手 →「直播」→「推流」，生成推流地址与密钥 |
| YouTube | YouTube 直播 →「直播设置」，获取"流地址"和"流密钥" |

> 🔐 **密钥=直播密码，切勿截图外泄！** 泄露后别人可推流到你的直播间。且很多平台密钥会**定期变化**，重新开播前记得刷新复制。

1. **进入推流设置**：「文件 → 设置 → 推流」。服务选平台预设；没有则选"自定义"。
2. **填入服务器与密钥**：粘贴"服务器地址"到「服务器」，粘贴"推流密钥"到「推流码」，点「确定」。
3. **检查画面与声音**：确认预览正常、混音器音量条在动。
4. **开始直播**：点「开始直播」，回平台后台看是否"直播中"。首次建议先小号试播。
5. **监控状态**：盯右下角「丢帧」，一直 0 最理想；持续飙高就降码率（见第十一章）。

## 九、八大使用场景实战

这是本文精华。每个场景给出"要什么来源 + 怎么搭 + 注意什么"，照着做即可。

### 场景 1：游戏直播
> 适合：B站 / 抖音 / YouTube 游戏主播

- **来源组合**：游戏采集（或显示器采集）＋ 视频采集设备（摄像头）＋ 文本（标题/水印）
- **搭建要点**：游戏来源优先用**"游戏采集"**（性能最好）；摄像头缩小放角落；可再建"开局等待"场景放封面图。
- **参数建议**：1080p60、CBR 6000–9000 Kbps、优先 NVENC 硬编；带宽不足降到 1080p30 / 720p60。
- **避坑**：游戏黑屏 → 改用"游戏采集"并选对进程；画面卡 → 关预览或降码率；部分反作弊游戏需"窗口/显示器采集"。

### 场景 2：录屏教学 / 软件演示
> 适合：教程 UP 主、程序员、产品演示

- **来源组合**：显示器采集 ＋ 麦克风（讲解）＋（可选）鼠标高亮插件
- **搭建要点**：录整个屏幕用"显示器采集"；只录某软件用"窗口采集"防隐私泄露；确认麦克风音量正常。
- **参数建议**：1080p30 足够，本地录制用 CQP 18–20；编码器选硬件编码。
- **避坑**：麦克风底噪 → 加"降噪"滤镜；没声音 → 检查混音器与默认设备；文件过大 → 提高 CQP 数值（20→23）。

### 场景 3：网课 / 会议（屏幕+人像画中画）
> 适合：老师上网课、远程汇报

![图9-1 画中画布局](图9-1-画中画布局.png)

**图 9-1**　画中画布局：屏幕铺满，人像放角落。

- **来源组合**：显示器采集（课件）＋ 视频采集设备（人像）＋ 麦克风
- **搭建要点**：先加屏幕铺满，再加摄像头缩小拖到角落形成画中画；开启"虚拟摄像头"后，在腾讯会议/Zoom/钉钉里选"OBS Virtual Camera"即可把合成画面当摄像头用（见场景 4）。
- **避坑**：会议软件选不到 OBS → 点 OBS 右下角「启动虚拟摄像头」；画面颠倒/黑屏 → 检查来源顺序（上层会盖住下层）。

### 场景 4：虚拟摄像头（美颜 / 背景替换）
> 适合：视频会议、面试、社交软件

![图9-2 虚拟摄像头流程](图9-2-虚拟摄像头流程.png)

**图 9-2**　虚拟摄像头：把 OBS 合成画面"伪装"成摄像头设备，供所有视频软件调用。

- **来源组合**：视频采集设备（真实摄像头）＋ 图像（虚拟背景）＋ 文本（名牌）
- **搭建要点**：底层放背景图，上层放摄像头；可给摄像头加"色度键"做绿幕。点「启动虚拟摄像头」，会议软件里选"OBS Virtual Camera"。
- **避坑**：其他软件占用摄像头会冲突 → 先在 OBS 里关闭摄像头来源；虚拟摄像头分辨率在「设置 → 视频」统一控制。

### 场景 5：绿幕抠像（虚拟背景）
> 适合：直播换背景、网课出镜、特效画面

![图9-3 绿幕抠像原理](图9-3-绿幕抠像原理.png)

**图 9-3**　绿幕抠像原理：色度键把绿色区域变透明，人像"浮"出来叠到任何背景上。

- **来源组合**：图像/视频（背景，放底层）＋ 视频采集设备（绿幕前的人，放上层）
- **搭建要点**：右键摄像头来源 →「滤镜」→ 添加**"色度键"**→ 颜色选绿色，调"相似度/平滑度"直到绿幕干净、人像边缘不破。
- **避坑**：布光要均匀（绿幕不能有褶皱阴影）；别穿绿衣服；抠不干净调大"相似度"，边缘毛糙调"平滑度/溢出抑制"。

### 场景 6：多场景切换 / 多机位
> 适合：直播节目、多角度录制、带货

- **来源组合**：场景A（全景/摄像头1）＋ 场景B（特写/摄像头2）＋ 场景C（屏幕PPT）＋ 场景D（片头/待机）
- **搭建要点**：每个场景独立搭建画面，直播中点击不同场景即可**无缝切换**；「转场特效」选"淡入淡出"更柔和；多摄像头配多块采集卡接入。
- **避坑**：给常用场景设**快捷键**切换更快；开启「工作室模式」可先在后台调好下一场景再切出，避免观众看到调整过程。

### 场景 7：纯音频录制（播客 / 有声书）
> 适合：播客、配音、音乐 Demo

- **来源组合**：麦克风（音频输入采集）＋（可选）媒体源背景音乐
- **搭建要点**：不用加画面来源，只留麦克风；加"降噪"+"压缩器"滤镜提升音质。录制后文件带封面画面，可导入剪辑软件导出纯音频。
- **避坑**：想保留**多轨**（人声/背景音分开）→ 用「设置 → 输出 → 高级 → 录像 → 音频轨道」配置多轨。

### 场景 8：回放缓存（精彩瞬间）
> 适合：游戏高光、突发镜头回录

- **原理**：OBS 后台持续缓存最近 N 秒画面，按一下快捷键就把"刚刚那一段"存成文件，无需全程录像。
- **开启方法**：「设置 → 输出 → 回放缓存」开启并设时长（如 60 秒）；「设置 → 热键」给"保存回放缓存"设快捷键（如 F8）。
- **用法**：打出精彩操作 → 按 F8 → 最近 60 秒自动保存，适合"不想一直录、又怕错过高光"。

## 十、进阶技巧与常用插件

### 10.1 给来源加滤镜

右键任意来源 →「滤镜」→ 点 `+` 添加：

| 滤镜 | 作用 | 典型场景 |
| --- | --- | --- |
| **降噪（噪声抑制）** | 去除麦克风底噪、电流声 | 录课、直播人声更干净 |
| **噪声门** | 低于阈值的声音自动静音 | 不说话时消除杂音 |
| **增益** | 放大/降低音量 | 麦克风声音太小 |
| **色度键** | 绿幕/蓝幕抠像 | 虚拟背景（场景 5） |
| **色彩校正 / LUT** | 调色、套滤镜风格 | 画面偏色、风格化 |
| **模糊** | 打码/模糊局部 | 遮挡隐私信息 |

### 10.2 常用插件推荐

32.0 起 OBS 内置"插件管理器"（菜单「工具」中），安装插件更方便：

- 📱 **obs-websocket**：手机/网页远程控制 OBS 开始、停止、切场景。
- 🎨 **StreamFX**：模糊背景、3D 变换、更高质量滤镜等进阶效果。
- 💬 **弹幕/字幕插件**：把直播弹幕显示到画面；Whisper 类插件可实时自动生成字幕。
- 🎛️ **高级转场/倒计时**：丰富的转场动画、"即将开播"倒计时组件。

> 📌 **找插件**：首选 OBS 官网论坛 / GitHub 知名项目，谨慎安装来路不明的插件，安装后重启 OBS 生效。

### 10.3 让画面更专业的小技巧

- **转场**：「转场特效」选"淡入淡出 300ms"或"剪切"，切换不突兀。
- **锁定来源**：预览区点来源 → 右上角"锁"图标，防止误拖动。
- **工作室模式**：「控件」里开启，后台预览 + 前台播出分离，适合正式直播。
- **快捷键**：把"开始/停止录制、切场景、保存回放"都设上快捷键。

## 十一、常见问题排查

| 现象 | 常见原因 | 解决办法 |
| --- | --- | --- |
| **画面全黑** | 来源没添加/选错显示器；笔记本双显卡切换；窗口受保护 | 重新添加来源并选对显示器；"窗口采集"换"游戏采集"；用"高性能"显卡启动 OBS |
| **没有声音** | 默认设备选错、混音器静音、来源没加音频 | 「设置→音频」选对设备；混音器看音量条、取消静音 |
| **直播卡顿/丢帧** | 码率超过上行带宽、CPU/GPU 满载 | 降低码率与分辨率；改硬件编码；关预览；减少来源 |
| **录像文件打不开/损坏** | 用了 MKV 没重封装、断电/崩溃 | 用 Hybrid MP4/MOV 默认格式，或"完成后重封装为 MP4" |
| **推流失败/连不上** | 服务器地址或密钥填错/过期 | 重新复制推流地址与密钥，确认无多余空格 |
| **麦克风底噪大** | 环境噪声、增益过高 | 给麦克风加"降噪"+"噪声门"滤镜 |
| **录出来模糊** | 码率过低、输出分辨率被缩小 | 提高码率；确认输出分辨率为 1080p |
| **摄像头被占用** | 其他软件占用了摄像头 | 关闭占用软件，或在 OBS 里重新添加该设备 |

## 十二、附录：快捷键与参数速查

### 12.1 常用快捷键（可自定义）

| 功能 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 开始/停止录制 | 无默认（建议设 `F9`） | 在「设置 → 热键」自定义 |
| 开始/停止直播 | 无默认（建议设 `F10`） | 同上 |
| 保存回放缓存 | 无默认（建议设 `F8`） | 需先开启回放缓存 |
| 切换场景 | 可设为 `1`–`9` | 直播中一键切画面 |
| 静音麦克风 | 可自定义 | 临时闭麦很实用 |

### 12.2 参数速查卡

- 🎬 **本地录屏（画质优先）**：1080p30 · 编码器 NVENC/x264 · CQP 18–20 · Hybrid MP4
- 📡 **直播推流（流畅优先）**：1080p60 · CBR · 6000–9000 Kbps · NVENC 硬编 · 上传带宽要够
- 👩‍🏫 **网课/会议**：1080p30 · 画中画布局 · 虚拟摄像头输出 · 麦克风加降噪
- 🎮 **游戏直播**：游戏采集 · 1080p60 · 摄像头角落 · 快捷键切场景
